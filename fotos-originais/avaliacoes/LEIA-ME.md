# Prints das avaliações

Coloque aqui os **prints das avaliações reais** dos anúncios das miniaturas (TikTok Shop), uma pasta por modelo:

```
fotos-originais/avaliacoes/jesus-sentado/
fotos-originais/avaliacoes/maria-sentada/
fotos-originais/avaliacoes/sao-jose-sentado/
fotos-originais/avaliacoes/sagrada-familia/
fotos-originais/avaliacoes/divino-espirito-santo/
fotos-originais/avaliacoes/boneco-de-neve-articulado/
```

O que cada print precisa mostrar:

- **Avaliações:** nome do cliente, estrelas, data e o texto inteiro (sem cortar). Um print por tela rolada.
- **Tela principal do anúncio:** nome do produto, nota média, nº de avaliações e nº de vendidos.

Regras do site para avaliações: só avaliações **de clientes reais**, copiadas como estão (primeiro nome e texto, sem foto de perfil). Avaliações escritas por IA ou por nós não entram como depoimento de cliente — isso é propaganda enganosa (Código de Defesa do Consumidor, art. 37).
